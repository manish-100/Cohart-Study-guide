# 2.18 — Getting Started with Next.js

> **Big picture:** Next.js is a **React framework**: it supplies routing, rendering modes, data conventions, and deployment integration so teams ship full-stack web apps with less glue code than “React only + assemble everything yourself.” This module explains **why** it dominates modern web development, how it differs from **React the library**, how to **bootstrap** a project, and how **file-based routing** plus **layouts** shape your architecture.
