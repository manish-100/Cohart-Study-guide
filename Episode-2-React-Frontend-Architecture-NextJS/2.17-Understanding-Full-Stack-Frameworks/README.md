# 2.17 — Understanding Full Stack Frameworks

> **Big picture:** A **full stack framework** unifies how you build **what users see** and **what runs on the server** inside **one application system**—shared tooling, types, routing, and often a single deployment unit. This module explains **why that matters**, what trade-offs you inherit, and how **2026-era meta-frameworks** (Next, Remix, Nuxt, SvelteKit, and others) shape real teams—not as a popularity contest, but as an engineering and product decision.
