**Q20.** Explain the "move function inside effect" strategy for fixing function dependencies:
```jsx
// Before: function in deps
const fetchData = () => fetch(`/api/${id}`);
useEffect(() => { fetchData(); }, [fetchData]); // Loops!

// After: function inside effect
useEffect(() => {
  const fetchData = () => fetch(`/api/${id}`);
  fetchData();
}, [id]); // Works!
```
