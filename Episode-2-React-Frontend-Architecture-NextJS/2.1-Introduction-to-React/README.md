# 2.1 — Introduction to React

> **Big Picture:** React changed how we think about building user interfaces. Instead of manually telling the browser what to change, you describe what the UI should look like and React figures out the most efficient way to make it happen. This topic takes you from understanding why React exists to writing your first component-based application.
