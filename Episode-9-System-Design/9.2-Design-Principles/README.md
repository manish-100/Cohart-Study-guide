# 9.2 — Design Principles

> **Big Picture:** Design principles are the **fundamental rules** that guide how you structure, organize, and evolve software. They sit between coding skills and architecture knowledge — helping you write code that is **readable, maintainable, extensible**, and resistant to the kind of rot that makes systems collapse under their own weight.
