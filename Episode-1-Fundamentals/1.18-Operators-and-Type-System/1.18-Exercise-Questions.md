## Answer hints

| Q | Hint |
|---|------|
| Q2 | Post-increment returns old value; pre-increment returns new |
| Q3 | `**` is right-associative: `2 ** (3 ** 2)` = `2 ** 9` = 512 |
| Q10 | `*` before `+`; `**` before `*` |
| Q15 | `>` and `>=` use numeric coercion; `==` has special null rules |
| Q16 | Both strings → lexicographic; string vs number → numeric |
| Q20 | Use `===` to fix: `return val === 0` |
| Q25 | `||` falls back for all falsy; `??` only for null/undefined |
| Q26 | Cannot mix `??` with `||` without parentheses |
| Q34 | `||=` assigns because 0 is falsy; `??=` does NOT assign |
| Q40 | `??=` only assigns for null/undefined; 0, "", false are kept |
| Q41 | Historical bug — null's type tag was 0 (same as objects) |
| Q48 | `typeof NaN === "number"` — add `!Number.isNaN(val)` check |
| Q51 | `[] → "" → 0`, `false → 0`, `0 == 0` |
| Q52 | Use `if (score == null)` or `if (score === null \|\| score === undefined)` |
| Q58 | `1+2=3`, `3+"3"="33"`, `"33"+4="334"` |
| Q61 | `[] → "" + "" = ""`; `[] → "" + "[object Object]"` |
| Q67 | `0`, `NaN`, `true`, `true`, `true`, `true`, `false` |
