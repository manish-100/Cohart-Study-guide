# 1.1 — How the Internet Works

> **Big Picture:** The internet is not a cloud. It is a massive network of physical cables, routers, and servers spanning every continent — connected by protocols (agreed-upon rules) that let any device talk to any other device.

## The Internet vs The World Wide Web

Many people use "internet" and "web" interchangeably, but they are different things:

```
┌─────────────────────────────────────────────────────────┐
│                    THE INTERNET                         │
│                                                         │
│   The global network of interconnected computers        │
│   (hardware + protocols: TCP/IP, cables, routers)       │
│                                                         │
│   ┌─────────────────────────────────────────────────┐   │
│   │          THE WORLD WIDE WEB (WWW)               │   │
│   │                                                 │   │
│   │  A service RUNNING ON the internet              │   │
│   │  (websites, HTML pages, HTTP protocol)          │   │
│   │  Invented by Tim Berners-Lee in 1989            │   │
│   └─────────────────────────────────────────────────┘   │
│                                                         │
│   Other services on the internet:                       │
│   • Email (SMTP/IMAP)                                   │
│   • File Transfer (FTP)                                 │
│   • Video Calls (WebRTC)                                │
│   • Messaging (XMPP)                                    │
│   • Gaming (custom protocols)                           │
└─────────────────────────────────────────────────────────┘
```

> **Key Takeaway:** The Web is just ONE application that runs on top of the Internet — like an app running on your phone's operating system.

## Timeline at a Glance

```
1969  ARPANET — 4 computers connected (UCLA, Stanford, UCSB, Utah)
1971  First email sent (Ray Tomlinson)
1973  TCP/IP invented (Vint Cerf & Bob Kahn)
1983  ARPANET switches to TCP/IP — the "birthday" of the internet
1989  Tim Berners-Lee proposes the World Wide Web at CERN
1990  First web browser & web server created
1991  WWW goes public
1993  Mosaic browser — first graphical browser for the masses
1993  CERN puts WWW in the public domain (free for everyone)
1994  Amazon, Yahoo founded — commercial web begins
1995  JavaScript invented (in 10 days by Brendan Eich)
1998  Google founded
2004  Web 2.0 era begins — Facebook, Gmail, AJAX
2007  iPhone launches — mobile web explodes
2008  Bitcoin whitepaper — seeds of Web 3.0
2014  Gavin Wood coins "Web 3.0"
2015  Ethereum launches — programmable blockchain
2020s Web 3.0 ecosystem grows — DeFi, NFTs, DAOs
```
