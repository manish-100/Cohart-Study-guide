# 1.14 — Exercise Questions: DOM Manipulation

Practice questions for all six subtopics in [Section 1.14](./README.md). Mix of short-answer, prediction, and DevTools / mini-script tasks.

## How to use this material (instructions)

1. **Read lessons in order** — [`README.md`](./README.md), then `1.14.a` → `1.14.f`.
2. **Answer closed-book first** — then compare to the matching lesson.
3. **Use DevTools** — Elements panel: inspect node types, `childNodes` vs `children` in Console.
4. **Interview prep** — [`1.14-Interview-Questions.md`](./1.14-Interview-Questions.md).
5. **Quick review** — [`1.14-Quick-Revision.md`](./1.14-Quick-Revision.md).
