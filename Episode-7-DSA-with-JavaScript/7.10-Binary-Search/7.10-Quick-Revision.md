# 7.10 — Quick Revision: Binary Search

[<< Overview](./README.md)

---

## Key concepts

| Variant | When | Template |
|---------|------|----------|
| Standard BS | Find exact match | lo<=hi, return mid |
| Lower bound | First >= target | lo<hi, hi=mid |
| Upper bound | Last <= target | lo<hi, lo=mid+1 |
| Rotated array | Sorted but rotated | Check which half sorted |
| BS on answer | Optimization | Feasibility check |
| Peak finding | Find local max | Compare mid vs mid+1 |
| 2D matrix | Row-col sorted | Flatten index |

## Common pitfalls
1. Off-by-one: lo<=hi vs lo<hi
2. Integer overflow in mid calculation
3. Infinite loop when lo=mid (use lo=mid+1)
4. Forgetting array must be sorted
5. Wrong comparison direction
