# 7.12 — Quick Revision: Linked List

[<< Overview](./README.md)

---

## Key concepts

| Operation | Singly | Doubly |
|-----------|--------|--------|
| Insert head | O(1) | O(1) |
| Insert tail | O(n) | O(1)* |
| Delete head | O(1) | O(1) |
| Delete tail | O(n) | O(1) |
| Search | O(n) | O(n) |
*with tail pointer

## Key patterns
- **Dummy head:** Simplifies edge cases
- **Fast/slow pointers:** Find middle, detect cycle
- **Reverse:** prev/curr/next iteration
- **Merge:** Compare heads, link smaller
