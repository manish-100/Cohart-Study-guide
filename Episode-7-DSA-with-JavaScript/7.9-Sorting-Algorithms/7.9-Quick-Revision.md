## Sorting comparison table

| Algorithm | Best | Avg | Worst | Space | Stable |
|-----------|------|-----|-------|-------|--------|
| Selection | O(n²) | O(n²) | O(n²) | O(1) | No |
| Insertion | O(n) | O(n²) | O(n²) | O(1) | Yes |
| Merge | O(n log n) | O(n log n) | O(n log n) | O(n) | Yes |
| Quick | O(n log n) | O(n log n) | O(n²) | O(log n) | No |
| Cyclic | O(n) | O(n) | O(n) | O(1) | No* |
| Counting | O(n+k) | O(n+k) | O(n+k) | O(k) | Yes |
| Heap | O(n log n) | O(n log n) | O(n log n) | O(1) | No |

## When to use which

- **Small data / nearly sorted:** Insertion sort
- **General purpose:** Quick sort (avg) or Merge sort (guaranteed)
- **Stability needed:** Merge sort
- **Memory constrained:** Heap sort or Quick sort
- **Integers 1..N:** Cyclic sort
- **Small range integers:** Counting sort
