# 7.11 — Quick Revision: Hashing

[<< Overview](./README.md)

## Key concepts

| Structure | Ops | Time | Use |
|-----------|-----|------|-----|
| Set | add/has/delete | O(1) avg | Uniqueness |
| Map | set/get/delete | O(1) avg | Key-value |
| Object | [] access | O(1) avg | Static config |

## Common patterns
- **Frequency count:** Map char/element → count
- **Seen before:** Set to track visited
- **Complement lookup:** Map for Two Sum pattern
- **Prefix sum + Map:** Subarray sum problems
