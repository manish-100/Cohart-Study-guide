## Easy

### E1. Identify the complexity of each code snippet

```js
// Snippet A
function a(n) { return n * 2; }             // O(?)

// Snippet B
function b(arr) {
    for (let i = 0; i < arr.length; i++) {} // O(?)
}

// Snippet C
function c(arr) {
    for (let i = 0; i < arr.length; i++)
        for (let j = 0; j < arr.length; j++) {}  // O(?)
}
```

<details><summary>Answer</summary>
A: O(1), B: O(n), C: O(n²)
</details>

---

### E2. What is the complexity of binary search?

<details><summary>Answer</summary>
O(log n) time, O(1) space (iterative), O(log n) space (recursive due to stack).
</details>

---

### E3. Simplify: O(3n² + 5n + 100)

<details><summary>Answer</summary>
O(n²) — drop constants and lower-order terms.
</details>

---

### E4. What is the complexity of this function?

```js
function mystery(n) {
    let i = n;
    while (i > 1) { i = Math.floor(i / 2); }
}
```

<details><summary>Answer</summary>
O(log n) — the loop variable halves each iteration.
</details>

---

### E5. Compare O(n) and O(n²) for n = 1000

<details><summary>Answer</summary>
O(n) = 1,000 operations. O(n²) = 1,000,000 operations. The quadratic algorithm
does 1000× more work.
</details>

## Medium

### E6. Analyze the complexity of this recursive function

```js
function f(n) {
    if (n <= 0) return;
    f(n - 1);
    f(n - 1);
}
```

<details><summary>Answer</summary>
O(2ⁿ) time — each call makes 2 recursive calls.
O(n) space — maximum call stack depth is n.
</details>

---

### E7. What is the complexity of finding all pairs in an array?

<details><summary>Answer</summary>
O(n²) — two nested loops with n(n-1)/2 pairs.
</details>

---

### E8. Optimize this from O(n²) to O(n)

```js
function hasDuplicate(arr) {
    for (let i = 0; i < arr.length; i++)
        for (let j = i + 1; j < arr.length; j++)
            if (arr[i] === arr[j]) return true;
    return false;
}
```

<details><summary>Answer</summary>

```js
function hasDuplicate(arr) {
    const seen = new Set();
    for (const x of arr) {
        if (seen.has(x)) return true;
        seen.add(x);
    }
    return false;
}
```

O(n) time, O(n) space.
</details>

---

### E9. What is the complexity of these nested loops?

```js
for (let i = 0; i < n; i++) {
    for (let j = 0; j < i; j++) { }
}
```

<details><summary>Answer</summary>
O(n²) — inner loop runs 0+1+2+...+(n-1) = n(n-1)/2 times.
</details>

---

### E10. Analyze space complexity of merge sort

<details><summary>Answer</summary>
O(n) — requires O(n) auxiliary space for merging, plus O(log n) call stack.
Total: O(n).
</details>

## Hard

### E11. What is the complexity of the Sieve of Eratosthenes?

<details><summary>Answer</summary>
O(n log log n) time, O(n) space.
</details>

---

### E12. Apply the Master Theorem to T(n) = 4T(n/2) + O(n)

<details><summary>Answer</summary>
a=4, b=2, d=1. log_2(4) = 2 > d=1 → Case 1 → O(n²).
</details>

---

### E13. Prove that comparison-based sorting is Ω(n log n)

<details><summary>Answer</summary>
A comparison sort builds a decision tree. With n! possible orderings, the tree
has n! leaves. A binary tree with n! leaves has height ≥ log₂(n!) = Θ(n log n).
Therefore, at least Ω(n log n) comparisons are needed.
</details>
