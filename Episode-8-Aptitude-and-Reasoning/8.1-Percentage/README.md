# 8.1 Percentage

## Overview

**Percentage** is the foundation of quantitative aptitude. The word comes from the Latin *per centum*, meaning "by the hundred." A percentage expresses a number as a fraction of 100. Almost every other arithmetic topic -- Profit & Loss, Simple Interest, Compound Interest, Data Interpretation -- depends on a solid understanding of percentages.

This section covers the concept from first principles through advanced applications, with enough practice material to build speed and accuracy for any competitive exam.

## One-Line Formula Cheat Sheet

```
Percentage          = (Part / Whole) x 100
Part                = (Percentage x Whole) / 100
Whole               = (Part x 100) / Percentage
% Increase          = [(New - Old) / Old] x 100
% Decrease          = [(Old - New) / Old] x 100
Successive Change   = a + b + (ab / 100)   (for two successive % changes a and b)
Multiplier (up r%)  = 1 + r/100
Multiplier (down r%)= 1 - r/100
```
