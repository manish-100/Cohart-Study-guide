# 8.14 Permutations and Combinations

## Overview

Permutations and Combinations form one of the most important and frequently tested topics in quantitative aptitude. This section builds a strong foundation from basic counting principles all the way to advanced selection and arrangement problems commonly seen in competitive exams, placement tests, and entrance examinations.

## What You Will Learn

- **Fundamental Counting Principle** -- the backbone of all counting problems
- **Factorials** -- notation, properties, and computation tricks
- **Permutations (nPr)** -- arrangements where order matters
- **Combinations (nCr)** -- selections where order does not matter
- **Distinguishing P vs C** -- the single most critical skill in this topic
- **Permutations with Repetition** -- words with repeated letters, number formations
- **Circular Permutations** -- seating arrangements around a table
- **Combinations with Restrictions** -- problems involving mandatory inclusion/exclusion
- **Selection from Groups** -- choosing from multiple distinct groups
- **Committee Formation** -- a classic exam favourite

## Prerequisites

- Basic arithmetic operations
- Understanding of factorial notation (covered in 8.14.a)
- Familiarity with algebraic manipulation

## Study Tips

1. **Always ask: "Does order matter?"** -- this single question decides P vs C.
2. Practice identifying problem types before attempting to solve.
3. Draw diagrams for seating/arrangement problems.
4. Verify answers using smaller cases when possible.
5. Memorize factorial values up to 10! for speed.
