# 8.8 Average

## Overview

**Average** (also called the **Arithmetic Mean**) is one of the most fundamental concepts in quantitative aptitude. It represents a single value that summarizes an entire data set. The concept appears directly in exam questions and also underpins topics like Data Interpretation, Statistics, and mixture problems.

Despite its apparent simplicity, average-based questions can range from straightforward calculations to tricky problems involving weighted averages, group combinations, and speed-distance scenarios. A deep understanding of the underlying formulas and shortcut techniques is essential for competitive exam success.

## One-Line Formula Cheat Sheet

```
Average (Mean)            = Sum of all observations / Number of observations
Sum of observations       = Average x Number of observations
Number of observations    = Sum / Average

Weighted Average          = (w1*x1 + w2*x2 + ... + wn*xn) / (w1 + w2 + ... + wn)

Avg of first n natural numbers          = (n + 1) / 2
Avg of first n even natural numbers     = (n + 1)
Avg of first n odd natural numbers      = n
Avg of consecutive numbers from a to b  = (a + b) / 2

Average Speed (same distance)           = 2*S1*S2 / (S1 + S2)

New avg when element added   = (Old_Sum + New_Element) / (n + 1)
New avg when element removed = (Old_Sum - Removed_Element) / (n - 1)

Combined average of two groups:
  = (n1*A1 + n2*A2) / (n1 + n2)
```
