# Answers and Explanations

---

## Easy

---

**Q1. Answer: (b) 30**

```
Sum = 10 + 20 + 30 + 40 + 50 = 150
Average = 150 / 5 = 30
```
Shortcut: These are in AP. Average = (10 + 50)/2 = 30.

---

**Q2. Answer: (b) 5.5**

```
Average of first n natural numbers = (n + 1) / 2
= (10 + 1) / 2 = 11/2 = 5.5
```

---

**Q3. Answer: (b) 120**

```
Sum = Average x Count = 15 x 8 = 120
```

---

**Q4. Answer: (c) 15**

```
5 consecutive odd numbers from 11: 11, 13, 15, 17, 19
Average = middle number = 15
Or: (11 + 19)/2 = 15
```

---

**Q5. Answer: (b) 21**

```
Average of first n even natural numbers = n + 1 = 20 + 1 = 21
```

---

**Q6. Answer: (b) Increases by 4**

```
When each element is increased by k, the average increases by k.
```

---

**Q7. Answer: (a) 25.71**

```
Old sum = 6 x 24 = 144
New sum = 144 + 36 = 180
New average = 180 / 7 = 25.71 (approx)
```

---

**Q8. Answer: (c) 50**

```
Average = (1 + 99) / 2 = 100 / 2 = 50
```

---

**Q9. Answer: (c) 140 kg**

```
When each element is multiplied by k, new average = old average x k.
New average = 70 x 2 = 140 kg
```

---

**Q10. Answer: (c) 3,000**

```
Total = 40 x 75 = 3,000
```

---

**Q11. Answer: (b) 15**

```
Average of first n odd natural numbers = n = 15
```

---

**Q12. Answer: (b) 23**

```
Total sum = 5 x 20 = 100
Sum of 3 numbers = 3 x 18 = 54
Sum of remaining 2 = 100 - 54 = 46
Average = 46 / 2 = 23
```

---

**Q13. Answer: (b) 35**

```
Sum = 3 x 40 = 120
Third number = 120 - 35 - 50 = 35
```

---

**Q14. Answer: (a) 10**

```
When each element is divided by k, new average = old average / k.
New average = 30 / 3 = 10
```

---

**Q15. Answer: (c) It lies between the smallest and largest numbers**

```
The average of a set of positive numbers always lies between
the minimum and maximum values (inclusive).
```

**Q27. Answer: (c) 17.67 years**

```
5 years ago, sum of 4 members' ages = 4 x 20 = 80
Present sum of those 4 = 80 + 4 x 5 = 100

Total = 100 + 4 + 2 = 106
Average = 106 / 6 = 17.67 years
```

**Q28. Answer: (b) 30**

```
n = 24
Numbers: 24, 26, 28, 30
Largest = 30
```

**Q30. Answer: (c) 37**

```

Tue + Wed + Thu = 3 x 38 = 114  ... (2)

Subtract (1) from (2):
Thu - Mon = 114 - 111 = 3
40 - Mon = 3
Mon = 37 degrees C
```

**Q31. Answer: (b) Rs 4,000**

```
P + Q = 2 x 5050 = 10,100  ... (1)
Q + R = 2 x 6250 = 12,500  ... (2)
P + R = 2 x 5200 = 10,400  ... (3)

Adding all three:
2(P + Q + R) = 33,000
P + Q + R = 16,500

P = 16,500 - (Q + R) = 16,500 - 12,500 = Rs 4,000
```

**Q32. Answer: (c) 180/47 km/h**

```
Let each distance = d km.
Total distance = 3d
Total time = d/3 + d/4 + d/5

LCM of 3, 4, 5 = 60:
= 20d/60 + 15d/60 + 12d/60 = 47d/60

Average speed = 3d / (47d/60) = 3 x 60 / 47 = 180/47 km/h ≈ 3.83 km/h
```
