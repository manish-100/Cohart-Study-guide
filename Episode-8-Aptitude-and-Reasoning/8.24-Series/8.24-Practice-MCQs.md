### Q15. (c) 81
Odd positions: 3, 8, 27, ? (3^1, 2^3, 3^3, ...). Actually: 3, 8, 27 -> these look like:
Alternate series: Odd: 3, 8, 27, ? Even: 4, 9, 28.
Odd: 3, 8, 27 -> differences 5, 19... not clean.
Try: 3^1=3, 2^3=8, 3^3=27, 4^3=64? But option is 81=3^4.
Odd positions: 3, 8, 27, 81 -> x8/3, x27/8... Not clean either.
Or: 3, 8, 27, 81 -> ratio ~2.67, 3.375, 3 -> approaching 3.
With +1 pattern: 3, 4, 8, 9, 27, 28, 81 -> the odd positions are 3, 8, 27, 81 which are 3^1, 8, 3^3, 3^4. Actually: 3, 8, 27, 81. Ratio: 8/3, 27/8, 81/27=3. 
Pattern: 3, 8, 27, 81. Each: x3 doesn't work for 3->8. But +1 then x3: 3(+1)4, 8(+1)9, 27(+1)28, 81. The even terms are each odd+1.
Answer: 81.
