# 8.2 Profit and Loss

## Overview

Profit and Loss is one of the most frequently tested topics in quantitative aptitude exams. It deals with commercial mathematics -- the calculations involved when goods are bought and sold. This section builds directly on **Percentage (8.1)** and forms the foundation for topics like Simple Interest, Compound Interest, and Partnership.

Mastering this topic requires a solid understanding of the relationship between Cost Price, Selling Price, and Marked Price, along with the ability to apply percentage calculations quickly under exam conditions.

## Formula Cheat Sheet

### Basic Definitions

```
Cost Price (CP)    = The price at which an article is purchased
Selling Price (SP) = The price at which an article is sold
Marked Price (MP)  = The price listed/labelled on the article (also called List Price)
```

### Profit and Loss

```
Profit         = SP - CP                        (when SP > CP)
Loss           = CP - SP                        (when CP > SP)

Profit %       = (Profit / CP) x 100
               = ((SP - CP) / CP) x 100

Loss %         = (Loss / CP) x 100
               = ((CP - SP) / CP) x 100
```

### Selling Price from Profit/Loss Percentage

```
SP = CP x (100 + Profit%) / 100                (in case of profit)
SP = CP x (100 - Loss%) / 100                  (in case of loss)
```

### Cost Price from Profit/Loss Percentage

```
CP = SP x 100 / (100 + Profit%)                (in case of profit)
CP = SP x 100 / (100 - Loss%)                  (in case of loss)
```

### Marked Price, Discount, and Markup

```
Discount           = MP - SP
Discount %         = (Discount / MP) x 100

Markup             = MP - CP
Markup %           = (Markup / CP) x 100

SP = MP x (100 - Discount%) / 100
MP = CP x (100 + Markup%) / 100
```

### Successive Discounts

```
For two successive discounts of d1% and d2%:

Equivalent single discount % = d1 + d2 - (d1 x d2) / 100
```

### Dishonest Dealer

```
Profit % = ((True Weight - False Weight) / False Weight) x 100

Or equivalently:
Profit % = (Error / (True Weight - Error)) x 100
```

### Combined Markup and Discount

```
Net Profit/Loss % = Markup% - Discount% - (Markup% x Discount%) / 100

(Result is profit if positive, loss if negative)
```

### Buy X Get Y Free

```
Effective Discount % = (Y / (X + Y)) x 100
```

## Key Exam Tips

- Profit and Loss percentages are **always calculated on Cost Price** unless stated otherwise.
- Discount percentage is **always calculated on Marked Price**.
- Markup percentage is **always calculated on Cost Price**.
- When a problem says "sold at X% profit," it means SP = CP x (100 + X)/100.
- In dishonest dealer problems, the dealer profits by using faulty weights -- always compare true weight vs. false weight.
