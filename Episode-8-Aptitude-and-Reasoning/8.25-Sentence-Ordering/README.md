# Section 8.25 -- Sentence Ordering (Para Jumbles)

## Overview

Sentence Ordering (also called **Para Jumbles**) is one of the most frequently tested topics in the Verbal Reasoning section of competitive exams. You are given a set of 4 to 6 sentences in a jumbled (random) order and must rearrange them into a logically coherent paragraph.

This section teaches you a systematic approach so that you can solve these questions quickly and accurately.

## How to Use This Section

1. **Read the concepts file first** -- understand every technique before attempting problems.
2. **Study the tips file** -- internalize the connector-word table and pattern-recognition shortcuts.
