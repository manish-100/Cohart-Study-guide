# 8.21 Quick Revision -- Blood Relation

## Family Tree Drawing Convention
```
  Male (M) ==== Female (F)       (Marriage)
            |
     +------+------+
     |      |      |
   Son  Daughter  Son             (Children / Siblings)
```

## Core Relationship Terms

| Chain | Result |
|:---|:---|
| Father's/Mother's son | Brother (or self) |
| Father's/Mother's daughter | Sister (or self) |
| Father's father | Grandfather (paternal) |
| Mother's father | Grandfather (maternal) |
| Father's brother | Uncle (paternal) |
| Mother's brother | Uncle (maternal) |
| Father's/Mother's sister | Aunt |
| Son's wife | Daughter-in-law |
| Daughter's husband | Son-in-law |
| Spouse's father/mother | Father/Mother-in-law |
| Spouse's brother/sister | Brother/Sister-in-law |
| Brother's/Sister's son | Nephew |
| Brother's/Sister's daughter | Niece |

## The "Only" Keyword
- "Father's only son" = self (if male)
- "Mother's only daughter" = self (if female)
- "Only child" = no siblings

## Gender-Neutral Words (TRAP!)
- Cousin, Child, Parent, Spouse, Sibling, Doctor, Friend

## Reverse Relationships
| If A is B's... | B is A's... |
|:---|:---|
| Father/Mother | Son/Daughter |
| Brother | Brother/Sister |
| Uncle/Aunt | Nephew/Niece |
| Grandfather | Grandchild |
| Father-in-law | Son/Daughter-in-law |

## Solving Strategy
1. Read the ENTIRE problem first
2. Draw the family tree (always!)
3. Mark gender clearly (M/F)
4. Process one clue at a time
5. Trace relationship from target person

## Coded Relationship -- Quick Steps
1. Write code meanings
2. Substitute one symbol at a time
3. Build mini family tree
4. Read the answer from the tree

## Speed Targets
- Simple (2 people): 15-20 sec
- Photo/pointing: 30-45 sec
- 3-4 person family: 45-60 sec
- 5+ person puzzle: 60-90 sec
