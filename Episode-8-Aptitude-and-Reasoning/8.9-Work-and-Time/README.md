# 8.9 Work and Time

## Overview

**Work and Time** is one of the most frequently tested topics in aptitude examinations. The core idea is simple: work is done at a certain rate, and the relationship between work, time, and rate governs every problem in this chapter. Mastering this topic requires a solid grasp of fractions, ratios, and the powerful **LCM method** that transforms tedious fraction arithmetic into quick mental math.

This section covers everything from basic one-person work problems to complex scenarios involving groups of workers with different efficiencies, alternating schedules, partial work, man-days, and the distribution of wages.

## Formula Cheat Sheet

### Fundamental Relationship

```
Work = Rate x Time

If A can complete a work in X days:
   A's 1 day work (rate) = 1/X
   A's work in D days     = D/X
```

### Combined Work (Two Workers)

```
If A does work in 'a' days and B in 'b' days:

   Combined rate = 1/a + 1/b = (a + b) / (a x b)

   Time together = (a x b) / (a + b)
```

### Combined Work (Three Workers)

```
If A, B, C do work in a, b, c days respectively:

   Combined rate = 1/a + 1/b + 1/c

   Time together = 1 / (1/a + 1/b + 1/c)
                 = (a x b x c) / (b.c + a.c + a.b)
```

### LCM Method (The Fast Way)

```
Step 1: Let Total Work = LCM of all given days
Step 2: Rate of each worker = Total Work / Their days
Step 3: Combined rate = Sum of individual rates
Step 4: Time together = Total Work / Combined rate
```

### Efficiency

```
Efficiency is inversely proportional to time:

   Efficiency(A) / Efficiency(B) = Time(B) / Time(A)

If A is 'k' times as efficient as B:
   Time(A) = Time(B) / k
```

### Man-Days (or Person-Days)

```
M1 x D1 x H1 = M2 x D2 x H2    (for same work)

Where: M = number of workers
       D = number of days
       H = hours per day

Extended: M1 x D1 x H1 / W1 = M2 x D2 x H2 / W2
          (when work quantities W1 and W2 differ)
```

### Alternating Work

```
When A and B work on alternate days:

Step 1: Find work done in 2 days (one cycle)
Step 2: Number of complete cycles = Total Work / Work per cycle
Step 3: Check remaining work and who finishes it
```

### Work and Wages

```
Wages are distributed in the ratio of work done:

   Wage(A) / Wage(B) = Work done by A / Work done by B
                      = Rate(A) / Rate(B)   (if they work same number of days)
```

### Partial Work

```
If A completes work in X days but leaves after D days:

   Work done by A = D / X
   Remaining work = 1 - D/X = (X - D) / X
```
