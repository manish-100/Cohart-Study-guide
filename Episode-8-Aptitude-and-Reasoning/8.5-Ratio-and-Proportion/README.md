# 8.5 Ratio and Proportion

## Overview

**Ratio** compares two or more quantities of the same kind by division. **Proportion** states that two ratios are equal. Together, they form one of the most frequently tested topics in quantitative aptitude -- appearing directly and as a building block inside Mixtures, Partnership, Time-Work, Ages, and Data Interpretation problems.

This section builds the topic from basic definitions through advanced applications like alligation, compounded ratios, and partnership profit-sharing, with enough depth and practice to handle any competitive exam.

## One-Line Formula Cheat Sheet

```
Ratio of a to b               = a : b  =  a/b
Proportion                     = a : b :: c : d  =>  a*d = b*c  (cross product)
Mean Proportional of a, b      = sqrt(a * b)
Third Proportional of a, b     = b^2 / a
Fourth Proportional of a,b,c   = (b * c) / a
Compounded Ratio of a:b, c:d   = ac : bd
Duplicate Ratio of a : b       = a^2 : b^2
Triplicate Ratio of a : b      = a^3 : b^3
Sub-duplicate Ratio of a : b   = sqrt(a) : sqrt(b)
Dividing Q in ratio a:b        = Qa/(a+b)  and  Qb/(a+b)
Dividing Q in ratio a:b:c      = Qa/(a+b+c),  Qb/(a+b+c),  Qc/(a+b+c)
Direct Proportion               = x1/y1 = x2/y2
Inverse Proportion              = x1*y1 = x2*y2
Alligation                      = (d2 - m) / (m - d1)   [cheaper:dearer]
Partnership Share                = (Capital x Time) ratio
```
