# 8.17 Geometric Progression (GP)

## Overview

A **Geometric Progression** is a sequence where each term is obtained by multiplying the previous term by a fixed non-zero number called the common ratio. GP concepts are essential for competitive exams, financial mathematics (compound interest, population growth), and advanced quantitative reasoning.
