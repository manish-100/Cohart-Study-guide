# 8.3 Simple Interest

## Overview

Simple Interest (SI) is one of the most fundamental topics in quantitative aptitude. It deals with the calculation of interest earned or paid on a principal amount over a period of time at a fixed rate. This topic is a staple in competitive exams (SSC, Banking, CAT, GATE, placement tests) and forms the foundation for understanding Compound Interest.

Simple Interest is calculated only on the **original principal** -- the interest does not earn interest. This makes it linear and predictable, unlike compound interest.

## Formula Cheat Sheet

```
Simple Interest:
    SI = (P x R x T) / 100

Amount:
    A = P + SI
    A = P (1 + RT/100)

Finding Principal:
    P = (SI x 100) / (R x T)
    P = (A x 100) / (100 + R x T)

Finding Rate:
    R = (SI x 100) / (P x T)

Finding Time:
    T = (SI x 100) / (P x R)

Finding SI from Amount:
    SI = A - P

Where:
    P = Principal (original sum)
    R = Rate of interest per annum (%)
    T = Time (in years)
    A = Amount (Principal + Interest)
    SI = Simple Interest
```

## Key Takeaway

Simple Interest is **linear** -- it grows at a constant rate. If you invest Rs. 1000 at 10% per annum, you earn Rs. 100 every year, regardless of how many years have passed. This simplicity is what makes SI problems solvable with basic algebra and mental math -- but the exam questions can still be tricky through clever framing and multi-step setups.
