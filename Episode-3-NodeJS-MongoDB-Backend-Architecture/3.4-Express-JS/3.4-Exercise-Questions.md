# 3.4 — Exercise Questions: Express.js

Practice questions for all six subtopics in [Section 3.4](./README.md). Short-answer, prediction, and coding tasks. Try each **without** reopening the lesson files first.

## How to use this material (instructions)

1. **Read lessons in order** — [`README.md`](./README.md), then `3.4.a` -> `3.4.f`.
2. **Answer closed-book first** — write bullets or a few lines, then compare to the lesson.
3. **Type code in a real project** — create a small Express app and test your answers with `curl` or Postman.
4. **Interview prep** — pair with [`3.4-Interview-Questions.md`](./3.4-Interview-Questions.md).
5. **Quick review** — [`3.4-Quick-Revision.md`](./3.4-Quick-Revision.md).
